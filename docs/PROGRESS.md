# DocVisRAG 项目进度文档

> 最后更新：2026-06-04

## 一、项目概述

DocVisRAG 是一个多模态文档检索增强生成（RAG）系统，面向复杂 PDF、扫描件、PPT 截图的智能问答。

核心组件：文档摄入（PyMuPDF + PaddleOCR + PP-Structure）、检索层（Dense FAISS + Sparse BM25 + ColPali 视觉）、生成层（Qwen2.5-VL-7B 多图推理）、评测层（Recall@K / EM / F1 / ANLS / Relaxed Accuracy）。
